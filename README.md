# 呼吸順起來｜嚴重氣喘照護旅程

Xolair 患者旅程互動網站設計原型，包含五個照護站點、島嶼與清單切換、就診準備清單下載及常見問題。

## 使用

使用靜態網站伺服器或部署平台開啟網站。無需安裝套件或建置。3D 場景透過 CDN 載入 Three.js 0.170.0，需要網路與 WebGL；不支援時保留插畫地圖。支援拖曳旋轉、鍵盤方向鍵調整視角、暫停動畫及重設視角。18 位人物沿步道行走；偏好減少動態的使用者預設暫停。

## GitHub Pages

若帳號方案支援此儲存庫的 Pages 功能，可前往 Settings → Pages，選擇 Deploy from a branch、main 分支及 / (root)。請先確認發布網站的存取範圍。
